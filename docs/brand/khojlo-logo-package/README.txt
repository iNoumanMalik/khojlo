KHOJLO — LOGO PACKAGE
=====================

The text is converted to outlines (Fraunces SemiBold), so no font needs to be installed.
Use the SVG files whenever you can: they stay sharp at any size.

WHICH FILE TO USE
- khojlo-logo-primary ........ default. Ink text with the gold-to-emerald pin, on light or cream backgrounds
- khojlo-logo-on-dark ........ cream text with a brighter pin, on ink or dark photo backgrounds
- khojlo-logo-flat ........... no gradient (solid emerald pin), for print, embroidery or stamps
- khojlo-logo-mono-black ..... one colour: fax, photocopies, engraving
- khojlo-logo-mono-white ..... one colour on emerald or other strong brand colours
- khojlo-icon-pin ............ the pin on its own, transparent background
- khojlo-app-icon-cream ...... launcher / store icon (rounded)
- khojlo-app-icon-emerald .... alternative launcher icon (rounded)
- khojlo-app-icon-cream-square  full-bleed square for Flutter launcher icons (iOS and Android apply their own mask)
- khojlo-banner-* ............ 1200x630 social / slide title images
- favicon.ico ................ web favicon (16-256 px)

COLOURS
  Ink      #2B2620     Cream    #FBF6EE
  Gold     #E3A73D     Emerald  #1D6D5A    Emerald light #2E9178
  Pin gradient: Gold -> Emerald, from top-left to bottom-tip

RULES
- Clear space: keep empty space around the logo at least the width of the pin head on every side.
- Minimum size: wordmark at least 90 px (or 25 mm) wide. Below that, use the pin icon alone.
- The pin's hole is a real cut-out, so the background shows through it.
- Don't recolour the text, stretch the logo, add shadows, or put the gradient logo on a busy photo.
