# Khojlo - Premium Mobile App UI Design Prompt

Design a world-class, production-ready mobile application called **Khojlo**, an AI-powered local business discovery platform.

This is **not** a traditional directory app like Google Maps or Yelp.

The goal is to create an emotional experience where users feel they are discovering hidden gems rather than browsing a list of businesses.

The design should immediately create an **"Ahh... wow."** reaction through motion, premium visuals, refined spacing, beautiful gradients, and thoughtful micro-interactions.

The overall experience should feel comparable to Apple-designed software, Airbnb, Arc Browser, Linear, Notion Calendar, Nothing OS, and modern award-winning mobile applications.

---

# Overall Design Direction

Create a luxurious light theme.

Avoid generic Material Design layouts.

Avoid Bootstrap-style cards.

Avoid flat interfaces.

Every screen should feel premium, immersive, elegant, animated, and expensive.

The interface should be modern enough that someone seeing it for the first time believes it belongs to a funded startup rather than a university project.

The design language should be consistent across the entire application.

Every screen should feel like it belongs to the same design system.
