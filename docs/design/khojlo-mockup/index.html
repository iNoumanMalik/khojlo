Khojlo mobile concept

Hidden-gem discovery, designed like a funded product.

This mockup translates your proposal and premium design direction into a portfolio-style mobile concept. It keeps the core system scope grounded in discovery, comparison, maps, reviews, AI assistance, messaging, and personalized recommendations while pushing the presentation toward a refined startup aesthetic.

4 key screens Home, map discovery, business detail, and AI concierge.
Luxury light mode Soft glass, layered surfaces, glowing highlights, and mesh depth.
Motion-led UI Breathing orb, animated search, floating pins, shimmer offers.
Ready to extend Useful as a design reference for Flutter, React, or a Behance case study.

Non-generic map flow
The concept intentionally avoids Google Maps and Yelp patterns. Discovery feels editorial, recommendations feel personal, and the visual rhythm changes from section to section so the app never looks like a repeated list of plain cards.
