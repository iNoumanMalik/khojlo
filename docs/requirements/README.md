## How to update a document

1. Make the change in the Markdown working copy (for the SRS) or note it in `document_review.md`.
2. Apply it to the Word file, update the table of contents (right-click → Update Field → Update entire table), and add a row to the revision history.
3. Export the PDF and replace the one in this folder.

The PDFs are what the committee has seen, so treat them as read-only records of each submission. The Markdown copies are where changes are drafted.
